# Ruleta Vanilla

Esta carpeta contiene una reimplementación sencilla del juego **Ruleta** usando únicamente HTML, CSS y JavaScript.

## Uso

Abre `index.html` en un navegador compatible con la Web Speech API.
Pulsa **Girar** para hacer girar la ruleta.
Cuando se detenga la ruleta, se reproducirá el audio "que imagen es esta" y se iniciará el reconocimiento de voz.
Responde con la palabra correcta. Si coincide con la selección, se reproducirá el audio de “correcto”.
